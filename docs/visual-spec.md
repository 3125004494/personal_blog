# 浏览器原型视觉规格

用户已选择浏览器原型并允许跳过 Image Gen，现已要求将当前方案发布至 GitHub Pages。

## 排版与组件
- 纯白背景 `#ffffff`、青绿色强调 `#078374`、正文深灰 `#202a2b`，无首屏装饰渐变或背景图。
- 字体优先使用 Microsoft YaHei / PingFang SC / Noto Sans SC 的中文无衬线栈，避免 Windows 的 Segoe UI 字体链接把中文正文回退为宋体；桌面主标题上限 76px、项目标题 29px、正文 16px；手机主标题 44–60px、项目标题 25px、正文 15px。
- 桌面内容最大宽 1200px；项目左文右图，以统一行布局保持秩序。
- 项目图完整显示，不裁切原截图；图片边框、微弱投影、图注统一。
- 手机 720px 以下改为单列；真实项目说明和链接始终可见。
- 交互：锚点导航、外部 GitHub / 摄影 Demo / 广船系统登录入口、点击成果图进入原生 dialog；键盘可关闭、焦点可恢复。广船系统按钮为“访问系统（需登录）”。
- 用户已明确确认公开指定系统登录信息，在访问按钮下方以简洁文字显示，不新增卡片或管理功能。
