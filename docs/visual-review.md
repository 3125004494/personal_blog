## 视觉修复
- 把中文字体提前到字体栈首位，并用 CDP 实际渲染字体检查验证。
- 截图等待图片 decode 和绘制，修复“资源加载成功但摄影截图区域空白”的 QA 问题。
- 加深图注、未公开状态与页脚小字，移除容易被理解为链接的状态下划线。
- 缩短桌面首屏上下留白，使项目更早出现。
- 用独立 Edge profile 消除用户浏览器扩展对截图的影响。
